## 📖 Giới thiệu (Overview)
Private Locket là giải pháp thay thế cho các mạng xã hội công cộng, tập trung vào quyền riêng tư và chia sẻ khoảnh khắc thời gian thực (Real-time). Dự án được xây dựng với kiến trúc **Client-Server**, cho phép người dùng tự lưu trữ dữ liệu (Self-host) và kết nối qua Internet thông qua giải pháp Tunneling.

## 🚀 Tính năng chính (Key Features)
* **📸 Đăng ảnh Real-time:** Chụp và upload ảnh ngay lập tức kèm Caption.
* **💬 Trò chuyện:** Bình luận, thả tim tương tác trực tiếp trên ảnh.
* **🔒 Quyền riêng tư:** Dữ liệu nằm hoàn toàn trên máy chủ cá nhân, không chia sẻ với bên thứ 3.
* **📱 Giao diện Mobile-first:** Tối ưu trải nghiệm vuốt chạm như ứng dụng di động (Locket Widget Style).

## 🛠 Công nghệ sử dụng (Tech Stack)
* **Backend:** Python (Flask Framework).
* **Database:** SQLite, SQLAlchemy.
* **Frontend:** HTML5, Jinja2, TailwindCSS (Dark Mode).
* **Infrastructure:** NPort / Cloudflare Tunnel (cho Public Access).
